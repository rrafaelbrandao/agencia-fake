# 💻 Agência Fake — Landing Page

## 🚀 Sobre o Projeto

Este projeto consiste em uma landing page para a **Agência Fake**, criada como atividade prática para aplicar conceitos de HTML5 e CSS3. A página apresenta os serviços de uma agência digital e utiliza um layout que se adapta a telas de computador, tablet e smartphone.

## ✨ Seções da Página

- **Navegação:** links para as principais áreas do site.
- **Apresentação:** chamada principal da agência, texto de divulgação e imagem de destaque.
- **Serviços:** cards para desenvolvimento de sites, aplicativos e marketing digital.
- **Rodapé:** identificação da agência e descrição do projeto.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estruturação do conteúdo da página.
- **CSS3:** estilos, organização do layout e adaptação para telas menores.
- **Google Fonts:** fontes Roboto e Lobster.

## 📱 Responsividade

O arquivo `css/responsivo.css` contém ajustes para telas com largura de até 1005px e 600px. Em telas menores, a apresentação e os cards de serviços ficam organizados em coluna, e os tamanhos de texto e espaçamentos são ajustados para facilitar a leitura.

## 📁 Estrutura do Projeto

```text
atividade-de-fixacao-css/
├── index.html
├── README.md
├── css/
│   ├── responsivo.css
│   └── style.css
└── img/
    ├── banner.png
    ├── marketing_icon.png
    ├── mobile-dev_icon.png
    └── web-dev_icon.png
```

- `index.html`: estrutura e conteúdo da página.
- `css/style.css`: estilos principais do projeto.
- `css/responsivo.css`: estilos para smartphones e tablets em orientação vertical.
- `img/`: imagens usadas na apresentação e nos cards de serviços.

## ⚙️ Como Executar o Projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto em um editor de código, como o Visual Studio Code.
3. Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server.

Não é necessário instalar dependências ou configurar um servidor back-end.

## 🎯 Objetivo de Aprendizado

Praticar a criação de uma página web com HTML e CSS, incluindo a organização de conteúdo em seções, uso de imagens e aplicação de regras de responsividade.
